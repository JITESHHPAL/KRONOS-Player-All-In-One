# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-10

### Added
- KRONOS web player with liquid-glass interface and smooth screen transitions
- Video player: tap-to-show controls, double-tap skip, audio language and video quality switching, subtitles, speed, screen size, landscape lock, picture settings, screenshots, resume playback
- Photo viewer: thumbnail grid, pinch/double-tap zoom, swipe, rotate, fit modes, slideshow
- Music player: queue, mini-player, shuffle, repeat, speed, sleep timer, lock-screen controls
- Recent screen for videos, photos and music
- Settings menu with pages and a back button
- Python server with byte-range support, zero-copy file sending, thumbnails and cached ffmpeg conversions
- Installable web app (manifest and service worker)
- Unit tests and GitHub Actions CI
